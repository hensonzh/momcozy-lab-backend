# 看便便完整用户体验闭环：交付状态（2026-10-23）

**工程闭环已实现；生产医学能力默认关闭。** 首发范围为中国/美国、中英文、出生至 1 周岁；UAT 不限制人数，但必须登录且拥有对应宝宝权限。

## 已实现

1. App 校验单张原图 ≤10 MiB、短边 ≥720px、JPEG/PNG/HEIC；逐张上传独立审核，未全部通过不能提交。
2. Product 在一次事务中持久化分析任务、宝宝背景快照、照片指纹、首卡、幂等记录和审计；数据库是唯一任务与结果权威。
3. Product worker 领取本地队列任务，重新核验权限、审核和原图指纹，生成无 EXIF 的临时 JPEG，单向调用独立无状态专项服务。
4. 独立服务通过 `gpt-6-sol`（可配置）只生成严格的视觉观察；`stool.medical.rules.2026-10-23.v1` 确定性生成风险、家长摘要和护理建议，并把规则版本写入 `stool.result.v1`。
5. Product 逐事件和终态校验、持久化并提供可重放 SSE；App 先显示卡片，再展示已经提交的颜色、性状、可见特征、关注程度、解读与建议。当前字段事件在完整模型响应后生成，不宣称为模型 token 级实时流。
6. App 支持失败、历史恢复、查看原照片、删除，以及完成后在后端追问能力开放时选择该次分析继续追问。
7. Agent 每次相关模型调用前向 Product 重新授权获取同次结果与有序图片；删除、撤销、换账号/宝宝/对话后 fail closed。

## 自动化证据

- Backend 单元/API/迁移测试；隔离 PostgreSQL+MinIO 的真实持久化和独立 ASGI 服务闭环。
- 独立服务使用假模型验证成功、失败、结构化请求、无状态和隐私边界；真实 OpenAI 调用不进入普通 CI。
- Flutter reducer、Repository、Widget 和整页测试覆盖字段流、完成卡、历史恢复、删除和带图追问引用。
- Agent 测试覆盖逐次授权、图片+结果物化、工具轮次再次授权、撤销后零次后续模型调用。
