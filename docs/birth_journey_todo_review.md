# 孕期计划事项审查清单

以下清单从当前孕期计划后端生成逻辑导出，包含事项名称和步骤。

## 基础孕周事项

### 做首次产检信息准备
1. 记录末次月经日期、验孕时间和验孕结果
2. 收集验孕试纸、抽血结果及已有检查报告
3. 整理正在服用的药物和叶酸/维生素补剂
4. 确认首次产检时间、科室和入口并完成预约
5. 准备身份证、医保卡和既往病史资料

### 做首次B超检查
1. 确认B超时间、地点及是否需要憋尿
2. 携带验孕/抽血结果及身份证件到院检查
3. 完成检查后确认报告获取时间与方式
4. 查看是否提示宫内妊娠、胎心胎芽等关键结果
5. 保存医院咨询入口或复查联系方式

### 做建档材料准备
1. 整理身份证、医保卡、就诊卡等基础证件
2. 按时间整理B超、抽血、尿检及病史资料
3. 记录过敏史、基础病史及长期用药情况
4. 记录叶酸及其他补剂名称与剂量
5. 按医院要求补齐缺失材料

### 做NT/早筛检查安排
1. 确认NT检查时间在孕周窗口内
2. 确认是否同天进行早筛抽血及空腹要求
3. 预约检查时间并写入日历
4. 保存NT数值及筛查结果
5. 设置复查或随访提醒

### 做唐筛/无创/羊穿决策
1. 携带NT及既往筛查结果参与产检决策
2. 确认适合唐筛、无创DNA或羊穿方案
3. 如做抽血筛查，确认时间与出报告方式
4. 如需羊穿，记录预约窗口及术前要求
5. 设置结果回看与后续处理提醒

### 做大排畸检查
1. 确认检查时间、地点及预计时长
2. 提前准备产检资料与既往报告
3. 安排当天交通与陪同人员
4. 完成检查并确认胎儿结构、羊水、胎盘结果
5. 保存复查入口及后续安排

### 做大排畸结果复查确认
1. 拍照保存报告并带给医生复看
2. 确认胎儿结构、胎盘、羊水及宫颈情况
3. 标记需复查或随访的项目
4. 确认复查时间或是否无需复查
5. 将复查时间加入日历

### 做糖耐检查（OGTT）
1. 确认检查时间并完成预约（如需预约制提前锁定）
2. 检查前8-12小时禁食禁水，确保空腹
3. 到院完成空腹抽血并饮用75g葡萄糖水
4. 按1小时/2小时（部分3小时）完成抽血
5. 检查结束后进食并观察身体反应

### 做胎动与异常观察
1. 选择每天固定时间观察胎动
2. 记录胎动明显增减变化
3. 观察头痛、水肿、腹痛、出血或流水
4. 保存医院急诊与产科联系方式
5. 出现异常及时联系医院

### 做下一次产检安排
1. 确认下次产检时间与挂号方式
2. 记录检查项目（B超/胎监/抽血等）
3. 确认是否需要空腹或特殊准备
4. 产检前准备既往报告与记录
5. 产检后更新下一次计划

### 做胎位与生长复查
1. 确认胎位、羊水及胎儿生长复查时间
2. 保存胎位及估重结果
3. 记录是否需要进一步观察或干预
4. 确认复查频率
5. 加入日历提醒

### 做GBS筛查与入院准备
1. 确认GBS筛查时间并完成采样
2. 保存GBS结果并标记阴性/阳性
3. 整理住院证件及关键产检资料
4. 确认入院入口及联系电话
5. 准备陪护与住院规则信息

### 做临产入院准备与联系流程
1. 保存产科/急诊/夜间入院联系方式
2. 明确宫缩、破水、见红的处理方式
3. 确认入院路线与交通方式
4. 准备待产资料袋并固定放置
5. 与陪同人确认分工与行动顺序

## 个性化条件事项

### 高龄风险产检补充
1. 将无创DNA/羊穿方案纳入产检决策
2. 确认血压、血糖、尿蛋白复查频率
3. 设置胎儿生长与羊水复查计划
4. 记录异常指标及随访规则
5. 更新产检关注指标

### IVF孕期管理
1. 校准孕周与预产期
2. 记录黄体支持及用药方案
3. 设置停药/减量提醒
4. 每次产检携带用药记录
5. 禁止自行调整用药

### 多胎管理
1. 确认双胎/多胎类型
2. 设置更密集产检与胎监计划
3. 记录宫颈长度与早产风险
4. 设置早产预警信号
5. 保存急诊联系方式

### 把没做完的产检安排上
1. 把已完成、未预约、等结果和需复查项目分成四类
2. 给未预约项目补上日期、地点和是否需要空腹
3. 给需复查项目写下复查原因、时间窗口和报告携带要求
4. 把等结果的项目设置报告回看提醒
5. 下次产检带着这张清单逐项确认

### 剖宫产/分娩准备资料
1. 整理既往剖宫产手术资料
2. 记录胎盘位置与间隔情况
3. 准备术前沟通要点
4. 预留分娩方式决策时间
5. 设置产前评估提醒

### 基础病管理
1. 记录基础病及用药情况
2. 设置专科与产科复查联动
3. 记录关键监测指标
4. 更新异常处理规则
5. 保存联系路径

### 把医生提醒设成复查和观察提醒
1. 把医生提醒原话写下来，并标出对应的检查或观察点
2. 确认每条提醒对应的复查日期、地点和报告要求
3. 把需要每天观察的变化设置成提醒
4. 写下哪些表现需要当天联系医院
5. 复查后把医生的新要求继续更新进计划

### 做顺产临产联系准备
1. 保存规律宫缩/破水/见红处理方式
2. 确认无痛分娩与陪产规则
3. 设置入院路线与电话
4. 记录分娩沟通偏好
5. 提前同步陪同人

### 做住院材料与沟通准备
1. 整理身份证、医保卡及产检资料
2. 按顺序整理关键检查与报告
3. 记录过敏史及长期用药
4. 写清分娩偏好与沟通重点
5. 入院前再次核对医院要求

### 做陪同人分工确认
1. 明确联系医院负责人
2. 明确资料与证件携带负责人
3. 明确交通与导航负责人
4. 汇总所有联系方式与入口
5. 临产前统一复核流程

## 生活与安全管理

### 做胎动与风险观察
1. 固定时间观察胎动变化
2. 记录异常症状变化趋势
3. 保存急诊联系入口
4. 设置风险触发条件
5. 出现异常及时联系医院

### 做久坐/久站/疲劳管理
1. 设置定时休息与起身提醒
2. 每45-60分钟活动2-3分钟
3. 久站后及时坐下抬腿休息
4. 记录疲劳与水肿情况
5. 出现异常症状及时就医
