# 孕期计划事项审查清单

以下清单从当前孕期计划后端生成逻辑导出，包含事项名称和步骤。

## 基础孕周事项

### 准备第一次看医生要带的信息
1. 写下末次月经第一天、验孕日期和验孕结果
2. 把验孕试纸照片、抽血结果或已有报告放进产检资料
3. 列出正在吃的药、叶酸、维生素和其他补剂
4. 预约或确认首次就诊入口，并记下科室、时间和地点
5. 就诊当天带身份证件、医保材料和既往病史资料

### 约好B超，也记得看结果
1. 预约或确认 B 超日期、地点和是否需要憋尿
2. 检查当天带上验孕或抽血结果、身份证件和就诊卡
3. 做完后当场问清报告什么时候出、在哪里看
4. 拿到报告后看是否写明宫内妊娠、胎心胎芽或需复查
5. 把异常时联系医院的电话或线上入口存到手机

### 把建档材料放在一起
1. 把身份证件、医保材料、就诊卡和建档要求放进同一资料袋
2. 按时间顺序整理已有 B 超、抽血、尿检和病史报告
3. 单独写下过敏史、基础病、手术史和长期用药
4. 把叶酸、钙铁、维生素等补剂名称和剂量记在手机里
5. 建档前一天核对医院要求，缺材料就先放进下次补交提醒

### 约好NT/早筛并设置提醒
1. 确认 NT 检查日期在医院要求的孕周窗口内
2. 同时确认早筛抽血是否同一天做、是否需要空腹
3. 把检查地点、到院时间和当天要带的材料写进日历
4. 检查后保存 NT 数值、报告结论和医生备注
5. 设置报告回看提醒，标出需要复查或转诊的提示

### 定下唐筛或无创怎么做
1. 把 NT、早筛、既往染色体筛查结果带到产检
2. 和医生确认适合唐筛、无创 DNA 还是羊水穿刺
3. 如果做抽血筛查，确认抽血时间、地点和出报告方式
4. 如果需要羊穿，先记下预约窗口、术前检查和术后注意事项
5. 设置报告回看提醒，并写下异常或临界结果的下一步入口

### 约好大排畸当天安排
1. 预约或确认大排畸日期、地点和预计检查时长
2. 检查前一天准备产检本、既往 B 超和筛查报告
3. 安排当天交通和陪同，给等待时间留出缓冲
4. 检查时问清胎儿结构、胎盘、羊水和宫颈相关结论
5. 保存需要补扫或复查时的预约入口和时间窗口

### 看完大排畸，定好是否复查
1. 拿到报告后先拍照保存，再带给产检医生回看
2. 逐项确认胎儿结构、胎盘位置、羊水和宫颈长度提示
3. 把报告里写着建议复查、随访或观察的内容圈出来
4. 和医生确定复查日期、复查项目，或确认无需复查
5. 把复查日期和需要带的报告加进日历提醒

### 做糖耐检查（OGTT）
1. 确认检查时间并完成预约；如需预约制，提前锁定号源
2. 按医院通知提前 8-12 小时禁食，饮水要求以医院口径为准
3. 到院完成空腹抽血后，在要求时间内喝完 75g 葡萄糖水或指定糖水
4. 按 1 小时、2 小时节点完成抽血；部分医院会加 3 小时
5. 等待期间尽量静坐，不进食、不喝含糖饮料，也不要剧烈走动
6. 检查结束后及时吃第一餐，并留意头晕、乏力等不舒服

### 每天固定看胎动和不舒服
1. 选一个宝宝平时活跃、自己也方便安静观察的固定时段
2. 每天在同一时段留意胎动变化，并记录明显变多或变少
3. 顺手观察头痛、视物模糊、水肿、腹痛、出血或流水
4. 把医院产科电话、急诊入口和线上问诊入口存到手机
5. 出现胎动明显变化、破水样流水或持续腹痛时按医院口径联系

### 定好下一次晚孕产检提醒
1. 确认下一次产检日期、地点和挂号方式
2. 把医生交代的 B 超、胎监、血压、尿常规等项目写进提醒
3. 如果有抽血或特殊检查，提前确认是否需要空腹
4. 产检前一天备好产检本、近期报告、血压血糖或胎动记录
5. 产检后把新增复查项目和下次日期立即加进日历

### 定好胎位和宝宝生长复查
1. 预约或确认胎位、胎儿生长、羊水和胎盘复查时间
2. 检查后保存宝宝估重、胎位、羊水和胎盘位置结论
3. 如果胎位不是头位，记录医生给的观察或复查时间
4. 确认是否需要增加 B 超、胎监或更密集产检
5. 把下次产检间隔和复查项目加进日历

### 做好GBS检查和入院材料
1. 确认 GBS 筛查是否已安排，以及采样日期和地点
2. 拿到 GBS 结果后拍照保存，并标记阳性或阴性结论
3. 把身份证件、医保材料、产检本和关键报告放进待产资料袋
4. 确认医院白天、夜间、急诊入院入口和联系电话
5. 把陪产、探视、住院押金或预登记要求写进清单

### 定好临产时怎么去医院
1. 保存医院产科、急诊和夜间入院联系电话
2. 写下规律宫缩、破水、见红和胎动异常时分别怎么处理
3. 确认从家到医院的路线、停车点或打车定位
4. 把待产资料袋、手机充电器和常用证件放在固定位置
5. 和陪同人同步谁联系医院、谁拿材料、谁负责出发路线

## 个性化条件事项

### 把高龄要看的项目加进产检
1. 把唐筛、无创 DNA 或羊穿选择放进下一次产检沟通
2. 确认血压、血糖和尿蛋白是否需要更早或更频繁复查
3. 把胎儿生长、胎盘位置和羊水复查时间写进日历
4. 如果已有异常指标，记录医生给的复查频率和联系阈值
5. 产检后立即更新下一次要看哪些指标

### 把IVF复查加进日历
1. 按移植日期或医生确认口径校准当前孕周和预产期
2. 列出黄体支持、抗凝或其他用药名称和剂量
3. 把停药、减量或复查日期加入日历提醒
4. 每次产检带上生殖科或保胎相关用药记录
5. 停药或调药前先按医生口径确认，不自行调整

### 定好多胎复查和早产提醒
1. 确认双胎或多胎类型，并把类型写进产检资料
2. 把每个宝宝的生长、羊水和胎盘复查时间加进日历
3. 确认是否需要宫颈长度、胎监或更密集产检
4. 写下早产信号，比如规律宫缩、破水样流水或出血
5. 保存医院产科、急诊和夜间入院联系方式

### 把没做完的产检安排上
1. 把已完成、未预约、等结果和需复查项目分成四类
2. 给未预约项目补上日期、地点和是否需要空腹
3. 给需复查项目写下复查原因、时间窗口和报告携带要求
4. 把等结果的项目设置报告回看提醒
5. 下次产检带着这张清单逐项确认

### 定好从产检到入院怎么走
1. 保存当前阶段的产检频率和下一次产检项目
2. 把医院建档、产检、急诊和入院入口分开记清楚
3. 写下规律宫缩、破水、见红分别先做什么
4. 把待产资料袋和重要证件固定放在同一位置
5. 把这套流程发给陪同人一起过一遍

### 准备上次剖宫产资料给医生看
1. 准备上次剖宫产原因、孕周、手术医院和出院小结
2. 写下两次怀孕间隔和这次胎盘位置等相关信息
3. 把手术记录或能找到的关键病历拍照保存
4. 下次产检主动讨论这次顺产或剖宫产评估
5. 把术前检查、入院时间和麻醉沟通先放进后续计划

### 把基础病复查放进产检日历
1. 列出基础病名称、当前用药、剂量和最近一次复查结果
2. 产检时确认这些药是否需要继续、调量或换药
3. 把产科复查和专科复查日期放到同一日历
4. 记录需要重点看的指标，比如血压、血糖、甲功或免疫指标
5. 保存指标异常时联系产科或专科的方式

### 把医生提醒设成复查和观察提醒
1. 把医生提醒原话写下来，并标出对应的检查或观察点
2. 确认每条提醒对应的复查日期、地点和报告要求
3. 把需要每天观察的变化设置成提醒
4. 写下哪些表现需要当天联系医院
5. 复查后把医生的新要求继续更新进计划

### 定好剖宫产术前准备
1. 确认术前检查项目、麻醉评估和抽血心电图时间
2. 把入院日期、禁食禁水开始时间写进提醒
3. 准备住院证件、产检报告和既往手术资料
4. 和陪同人分好术后陪护、下床、取物和联系医生的事
5. 写下伤口观察、排气进食和下床活动的医院口径

### 确认生产医院怎么入院
1. 确认生产医院是否需要预登记、住院预约或押金准备
2. 保存白天产科、夜间急诊和入院办理入口
3. 整理医院要求的身份证件、医保材料和产检报告
4. 确认陪产、探视、待产包和病房用品规则
5. 把医院地址、停车点或打车定位发给陪同人

### 把临产分工发给家人确认
1. 列出临产当天需要支持人负责的事项
2. 指定谁联系医院、谁拿证件报告和待产包
3. 指定谁负责交通路线、停车或打车定位
4. 把医院入口、联系电话和备用方案发给支持人
5. 和支持人约定出现宫缩、破水、见红时谁先行动

### 定好产后48小时喂养求助方式
1. 写下产后 48 小时优先亲喂、混合还是泵奶
2. 准备住院时要问的含乳、吸吮、补奶和泵奶问题
3. 保存医院护士、母乳门诊或 IBCLC 咨询入口
4. 把乳头疼痛、涨奶、宝宝尿布和体重变化列为观察点
5. 和家人同步不要随意加奶或用奶嘴的沟通口径

### 把上一胎经历用到这次准备
1. 写下上一胎主要分娩方式和当时最影响体验的一件事
2. 如果有早产、出血、撕裂或感染，单独标出来
3. 把这些经历放进下次产检沟通清单
4. 根据上一胎恢复难点提前安排产后支持
5. 和陪同人同步这次想避开或重点准备的事项

### 定好顺产临产怎么联系医院
1. 保存规律宫缩、破水、见红和胎动异常时的联系步骤
2. 确认无痛分娩、陪产、导乐或待产室规则
3. 把入院路线、急诊入口和联系电话存到手机
4. 写下分娩沟通偏好，比如镇痛、体位和陪同需求
5. 把临产出发分工发给陪同人确认

## 生活执行事项

### 固定通勤后的 20 分钟休息
1. 选定到家或到办公室后的固定 20 分钟休息时段
2. 把这段时间加入日历，并设置每天同一时间提醒
3. 休息时先坐下或半躺，喝水，避免立刻处理家务或工作
4. 告诉支持人这 20 分钟不安排杂事或临时任务
5. 连续执行 3 天后记录腰酸、腿胀或疲惫有没有变化

### 设置久坐后的起身提醒
1. 选一个 45-60 分钟提醒间隔，放进手机或电脑提醒
2. 提醒响了就起身 2-3 分钟，喝水、走几步或换坐姿
3. 午后或下班前补一次小腿伸展，避免一直坐到腿胀
4. 把腰酸、腿抽筋或脚肿出现的时间记下来
5. 如果水肿明显、单侧腿痛或胸闷气短，按医院口径联系

### 今晚固定睡前 30 分钟降噪
1. 睡前 30 分钟停掉工作消息和复杂沟通
2. 把明天必须做的一件事写进提醒，避免睡前反复想
3. 准备水杯、夜灯和舒服的枕头位置
4. 记录今晚入睡时间、夜醒次数和醒来原因
5. 如果持续失眠、头痛或明显焦虑，放进下次产检沟通清单

### 安排久站后的坐下休息点
1. 选出今天最容易久站的时段，比如排队、做饭或通勤
2. 提前安排一个能坐下、抬脚或靠墙休息的位置
3. 每站 20-30 分钟就坐下休息几分钟
4. 请支持人帮忙替换一次需要久站的任务
5. 如果出现明显腹痛、宫缩感、出血或流水，按医院口径联系

### 安排今天能完成的减压动作
1. 选出今天最影响执行的一件事，只保留一个优先项
2. 把它拆成 15 分钟内能完成的动作，比如预约、整理或发消息
3. 给这个动作定一个具体开始时间
4. 告诉支持人你需要的一个帮助，越具体越好
5. 完成后把下一个动作放到明天，不把所有事情堆到今天

## 安全提醒事项

### 先确认是否需要联系医院或医生
1. 先暂停普通准备事项，优先处理当前不舒服或异常变化
2. 记录症状开始时间、持续多久、有没有加重和伴随表现
3. 按医院产科、急诊或医生口径确认是否需要当天就医
4. 如果医院要求观察，写下观察频率和再次联系的触发条件
5. 保存这次联系结果，并把后续复查或观察提醒加进日历

## 临产住院事项

### 定好临产后怎么联系医院
1. 保存产科门诊、急诊、夜间入院和护士站联系电话
2. 写下规律宫缩、破水、见红和胎动异常分别怎么处理
3. 把医院地址、急诊入口、停车点或打车定位发给陪同人
4. 把待产资料袋、手机充电器和常用证件放在固定位置
5. 约定临产时谁先联系医院、谁拿材料、谁负责出发路线

### 把住院材料和沟通重点放一起
1. 把身份证件、医保材料、就诊卡和住院押金准备放进资料袋
2. 按时间顺序放好关键产检报告、B 超、筛查和复查结果
3. 单独写下过敏史、基础病、长期用药和特殊医嘱
4. 把分娩方式、镇痛、陪产和喂养沟通重点写成一页纸
5. 入院前一天再核对医院最新证件、陪护和探视要求

### 和陪同人过一遍入院分工
1. 指定一个人负责联系医院并记录医生或护士回复
2. 指定一个人负责拿证件、产检报告和待产资料袋
3. 指定一个人负责打车、开车、停车或路线导航
4. 把医院电话、入口定位和备用方案发到同一个聊天里
5. 临产前和陪同人用 5 分钟过一遍分工
