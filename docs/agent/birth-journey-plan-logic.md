# 生产全过程计划阶段内容医学审查稿

本文档只用于医学同事审查“生产全过程计划”各阶段内容是否合理。

请重点看：

- 阶段划分是否符合孕产期实际节奏。
- 每个阶段的目标是否合适。
- 注意事项是否准确，不过度、不遗漏关键风险。
- 准备工作是否具体、可执行，不会增加不必要焦虑。
- “我能帮你做”的服务引导是否适合该阶段。

## 阶段划分

生产全过程计划默认从妈妈当前孕周开始，覆盖到产后 42 天。

| 阶段 | 时间范围 | 说明 |
| --- | --- | --- |
| 孕早期 | 怀孕 0 周到 13 周 6 天 | 仅当前不足 14 周时展示。 |
| 孕中期 | 怀孕 14 周到 27 周 6 天 | 当前不足 28 周时展示。 |
| 孕晚期 | 怀孕 28 周到 36 周 6 天 | 重点进入入院、待产包、分娩沟通和出发准备。 |
| 临产期 | 怀孕 37 周到预产期后约 7 天 | 重点是联系医院、判断出发和支持人执行。 |
| 住院期 | 入院当天到出院当天 | 重点是院内沟通、记录、喂养启动和出院前确认。 |
| 产后期 | 出院后 0 到 42 天 | 重点是妈妈恢复、宝宝喂养和家庭照护节奏。 |

已经过去的产前阶段不会展开。

## 孕早期

适用：当前不足 14 周。

| 模块 | 内容 |
| --- | --- |
| 阶段目标 | 先确认怀孕和首次产检/建档安排，把需要带去问医生的信息准备好。 |
| 注意事项 | 不用急着准备待产包或分娩细节，先把产检安排和身体信号看住。 |
| 准备工作 | 确认首次产检或建档时间，并记下医院要求携带的材料。<br>把末次月经、验孕/检查结果、正在吃的药和补充剂整理好，下次产检带上。<br>把既往病史、过敏史、流产史或特殊情况列成要问医生的问题。<br>和支持人先说好产检陪同、接送、请假和休息安排。 |
| 我能帮你做 | 帮你整理首次产检要问医生的问题。<br>帮你做建档/产检前准备清单。<br>帮你梳理早孕期需要联系医生的信号。<br>帮你记录预产期、检查结果和待确认事项。 |

## 孕中期

适用：怀孕 14 周到 27 周 6 天；如果妈妈还在孕早期，也会作为后续阶段展示。

| 模块 | 内容 |
| --- | --- |
| 阶段目标 | 把产检节奏、生产医院方向和产后前两周支持人先定出框架。 |
| 注意事项 | 不用把生产准备一次做完，先把下次产检、医院选择和家里支持这三件事问清楚。 |
| 准备工作 | 把下次产检最想确认的 3-5 个问题写下来，优先问检查结果、后续产检节奏和是否有特殊提醒。<br>确认生产医院或生产地点的候选项，记录建档、转诊或预约规则。<br>和支持人初步分工：产检谁陪、临时不舒服谁接送、产后前两周谁能到场。<br>如果还没想好喂养方式，先记下想问医生、护士或 IBCLC 的问题。 |
| 我能帮你做 | 帮你把下次产检问题整理成 3-5 个重点。<br>帮你整理要向医院确认的流程问题。<br>帮你把产后前两周支持人分工写成草稿。<br>帮你按孕周拆出下一步准备顺序。 |

## 孕晚期

适用：怀孕 28 周到 36 周 6 天；如果妈妈更早进入计划，也会作为后续阶段展示。

| 模块 | 内容 |
| --- | --- |
| 阶段目标 | 把医院流程、待产包、分娩沟通和出发安排逐项落地。 |
| 注意事项 | 这个阶段先按顺序准备，先确认医院规则，再整理待产物品和分娩沟通，最后做出发核对。 |
| 准备工作 | 向医院确认预登记、入院条件、陪产/探视、夜间入口、停车或打车路线。<br>按分娩方式、喂养计划和住院天数整理待产包，只补真正缺的关键物品。<br>把疼痛缓解、陪产、生产偏好和宝宝出生后安排整理成给医护看的分娩沟通单。<br>和支持人约好临产时谁联系医院、谁拿包、谁负责交通和家里照护。 |
| 我能帮你做 | 帮你整理医院流程确认清单。<br>帮你整理个性化待产包清单。<br>帮你把生产偏好整理成分娩沟通单。<br>帮你做出发前核对和支持人分工。 |

## 临产期

适用：怀孕 37 周到预产期后约 7 天。

| 模块 | 内容 |
| --- | --- |
| 阶段目标 | 把联系医院的条件、话术和出发动作提前准备好。 |
| 注意事项 | 出现破水、出血多、胎动明显减少、规律宫缩加密、剧烈腹痛或头晕胸痛时，不要硬扛，按医院或医生指导联系医院。 |
| 准备工作 | 把医院电话、产科急诊入口和支持人电话放到最容易找到的位置。<br>提前写好联系医院时要说的内容：孕周、宫缩间隔、是否破水/出血、胎动变化和预计到院时间。<br>让支持人熟悉这套说法，并知道出发物品和重要材料放在哪里。 |
| 我能帮你做 | 帮你整理联系医院时的简短话术。<br>帮你做宫缩、破水和胎动变化记录模板。<br>帮你把出发核对压缩成临产版。 |

## 住院期

适用：入院到出院。

| 模块 | 内容 |
| --- | --- |
| 阶段目标 | 把院内沟通、喂养启动和重要信息记录交给明确的人负责。 |
| 注意事项 | 医疗处置以医院团队为准，但疼痛缓解、麻醉沟通、肌肤接触、喂养启动和陪护分工可以提前说清楚。 |
| 准备工作 | 入院后让支持人把分娩沟通单交给医护，并在你不方便说话时帮你补充重点。<br>约定谁记录宝宝出生时间、喂养时间、尿布、妈妈用药/检查和医生交代。<br>出院前集中问清复诊、伤口/恶露、喂养、宝宝黄疸或体重观察这些问题。 |
| 我能帮你做 | 帮你查看分娩沟通单里的重点。<br>帮你整理院内记录清单。<br>帮你整理出院前要问医生的问题。<br>帮你把住院期间的喂养问题带给 IBCLC 咨询。 |

## 产后期

适用：出院后 0 到 42 天。

| 模块 | 内容 |
| --- | --- |
| 阶段目标 | 先把妈妈恢复、宝宝喂养和夜间照护安排跑顺。 |
| 注意事项 | 发热、恶露突然增多或有异味、伤口红肿加重、乳房红肿疼痛，或宝宝尿布明显减少、精神差时，要联系医生、儿科或哺乳专业人士。 |
| 准备工作 | 出院当天确认妈妈复诊、宝宝儿科检查和需要观察的身体信号。<br>前一周记录喂养次数、尿布、妈妈疼痛/恶露/伤口和休息情况。<br>把夜间照护分清楚：谁喂、谁换尿布、谁安抚、谁保证妈妈连续睡一段。<br>产后 2-6 周复盘喂养、恢复和家庭支持缺口，必要时找医生或 IBCLC。 |
| 我能帮你做 | 帮你整理夜间照护分工。<br>帮你整理喂养、尿布和妈妈恢复记录。<br>帮你区分哪些信号需要联系医生或 IBCLC。<br>继续帮你看奶量、含乳和排乳节奏。 |

## 不同情况的补充逻辑

以下信息会让计划在对应阶段增加更贴合妈妈情况的内容。

| 用户情况 | 影响阶段 | 补充逻辑 |
| --- | --- | --- |
| 第一胎 | 孕晚期、临产期 | 加强入院流程、临产信号和支持人任务提醒。 |
| 不是第一胎 | 孕晚期 | 增加大宝接送、陪伴和夜间照护安排。 |
| 双胎或多胎 | 孕晚期 | 提醒产检和入院节奏更要按医生安排，不套用单胎时间表。 |
| 计划剖宫产 | 孕晚期、住院期、产后期 | 增加术前禁食、入院时间、住院天数、术后下床和伤口护理相关确认。 |
| 计划母乳、混合喂养或泵奶 | 住院期、产后期 | 增加含乳、涨奶处理、IBCLC/泌乳顾问支持等内容。 |
| 已确定生产医院或生产地点 | 孕晚期 | 围绕该医院确认预登记、陪产、探视、夜间入口、停车或打车规则。 |
| 有明确支持人 | 孕晚期、产后期 | 把支持人需要负责的事写清楚，例如出发、联系医院、记录、夜间照护和补给。 |
| 医生已经提醒过特殊情况 | 孕中期、孕晚期 | 提醒以医生和医院方案为准，并在产检时问清后续观察和入院时机。 |

## 医学审查问题

请重点判断：

- 每个阶段的目标是否符合该孕周/产后阶段。
- 注意事项是否准确，是否需要增加或删减。
- 准备工作是否具体可执行，是否会造成不必要焦虑。
- 红旗症状是否表达清楚。
- 不同情况的补充逻辑是否合理，是否需要增加更多医学场景。
