# 设备指导资料选择

当前已接入官方资料的型号：

- Air1 (BP334)

Air1 设备资料通过 `device_support` namespace 中的 `device_manual_search` 获取。不要用 `read_skill_file` 直接读取 `manual.md` 或 `faq.md`。

## manual.md

`manual.md` 是 Air1 官方说明手册，适合处理开箱指导场景下的问题。

优先读取 manual 的情况：

- 用户需要操作步骤、顺序或流程。
- 用户处于开箱、首次使用、安装、拆卸、清洁、消毒、充电、穿戴、App/蓝牙、倒奶、储奶等设备操作场景。
- 用户上传设备或配件图片，需要对照当前操作步骤核对可见部件或安装状态。
- 用户问某个操作是否允许，且答案依赖官方说明书的安全规则。

## faq.md

`faq.md` 是 Air1 常见问题整理，适合解决“是什么、为什么、是否正常、如何判断”的问题。

优先读取 FAQ 的情况：

- 用户问部件、功能、原理、用途或区别。
- 用户问某个现象是否正常、原因是什么、如何判断。
- 用户问吸力、漏气、漏奶、法兰尺寸、阀门、隔膜、App/蓝牙等问题背后的解释。
- 用户只是问单点知识问题，没有要求一步步操作。

## 调用规则

- 型号未知时先确认型号；不要用 Air1 资料猜测其他型号。
- 当前只支持 Air1/BP334。其他型号只能基于用户提供的官方材料处理，或转人工支持。
- 需要官方资料、步骤图片、FAQ、Quick Start 资源或客服工单草稿时，先加载 `device_support` namespace。
- 已经在当前会话加载过 Air1 manual 时，连续同型号步骤默认复用已有资料。
- 只有用户切换型号、提出新的 FAQ 型问题、当前步骤缺少必要图片，或前次结果不足时，才再次调用 `device_manual_search`。
- 工具返回字段和可用 `topic` 以工具 schema 与工具结果中的说明为准；

## 开箱指导流程

当用户表达刚收到、刚拿到、准备开箱、第一次用吸奶器，或不知道从哪里开始时：

1. 型号未知时，先确认是否为 Air1/BP334；确认前不要调用设备资料检索，也不要提前给说明书、视频或完整步骤。
2. 确认 Air1/BP334 后，调用 `device_manual_search(model="Air1", topic="unboxing")`。
3. 拿到工具返回结果后，先介绍产品亮点，再展示工具返回的 Quick Start PDF 和中文操作视频。
4. 然后询问用户是否需要一步步指导。
5. 用户确认后，按 manual 中的“首次使用推荐路径（开箱指引）”推进。

## 问题处理边界

- 操作类问题优先查 manual。
- 知识解释类问题优先查 FAQ。
- 型号不支持且用户没有提供官方材料时，不编造具体步骤或参数。
- 缺件、配件破损、配件不对、疑似产品缺陷、保修、退货、换货、订单、物流、联系客服等，使用 `support_ticket_draft_create` 创建客服工单草稿。
- 主机进水、冒烟、烧焦味、电池异常、充电线或适配器异常、受伤等安全风险，停止普通设备指导并使用客服工单草稿工具升级产品支持。
- 围绕同一问题完成一次聚焦排查仍无法解决时，不继续无限排查，转产品支持。

## 固定安全事实

- 主机不可水洗、浸泡、自行拆卸或自行更换电池。
- 只清洗官方说明书标明的可清洗部件。
- 部件破损、裂纹、变形或老化时，停止使用直到更换部件。
- 更高吸力不等于更多乳汁；以舒适档位为准。
- 吸奶不应产生明显疼痛；明显疼痛或过度不适时，停止吸乳并解除乳头周围密封。
