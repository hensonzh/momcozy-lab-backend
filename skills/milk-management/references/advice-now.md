# 当下建议

本 reference 用于回答“今天/现在/下一步怎么做”。它是当下建议，不是完整追奶、稳奶或减奶计划。

## 适用场景

- 用户问“今天怎么吸”“今天奶量要注意什么”“现在先做什么”“今天安排是什么”。
- 前端已经生成每日泌乳建议卡片，用户继续追问其中的状态、原因或下一步。
- 用户只想要今天可执行的动作，而不是长期计划。
- 分析结果显示需要先补记录、稳住节奏或观察当天信号。

不适用：

- 用户明确要生成追奶、稳奶或减奶计划：读取 `advice-plan.md`。
- 用户主要在问奶量够不够、趋势或宝宝摄入是否足够：先读取 `analysis.md`。
- 用户要新增、修改、删除、完成、跳过任务或补记录：读取 `execution-and-records.md`。
- 出现需要暂停普通奶量流程的情况：停止当下建议流程，回到 `SKILL.md` 的“暂停普通奶量流程的情况”处理。

## 数据使用

需要工具时，先通过 `tool_search` 加载 `milk_management` namespace。

- 看今天安排、未完成任务或日程执行：`milk_calendar_query`。
- 看今日状态、趋势或宝宝成长概览：`milk_status_query`。
- 只看过去一段时间记录和每日汇总：`milk_records_query`。
- 只有用户明确问“是否正常、够不够、偏低偏高、是否需要计划”时，才调用 `milk_assessment_evaluate`。

如果回答里要出现“原计划、当前计划、今天安排、未来几天先这样做、保留原来的安排、在原计划上加/减一次”等内容，必须以 `milk_calendar_query` 或 `milk_plan_query` 的结果为准。`milk_records_query` 返回的是实际发生记录，只能说“最近实际吸奶时间”，不能称为“原计划”。

不要为了当下建议默认生成计划草稿，也不要默认调用写入工具。

## 输出结构

可以压缩成自然短段，但内容只落在今天或下一步。

1. **今日状态**：稳定、记录补充中、奶量波动中、需要关注等短状态。
2. **今日重点**：今天最值得优先处理的一件事。
3. **现在怎么做**：只给可执行动作，例如按日程吸奶、避免间隔过长、补齐记录、观察身体感受。
4. **下一步入口**：如果存在风险或用户有担心，邀请继续分析或生成计划；不要直接跳到长期计划。

## 边界

- 不单独输出“喂养建议”段落；喂养数据只作为理解泌乳和宝宝摄入的背景。
- 不把连续异常直接写成“你需要追奶/减奶”。只能说“可能需要进一步看一下是否要调整计划”。
- 不承诺今天执行后奶量一定变化。
- 不写入 calendar；如果用户要调整日程、完成任务或补记录，转 `execution-and-records.md`。
- 不生成完整追奶、稳奶或减奶计划；如果用户确认想做计划，转 `advice-plan.md`。
- 不手工编排未来 3 天或 7 天的吸奶时间。需要基于计划调整时，先读取现有 calendar；需要生成新计划时，转 `advice-plan.md` 并使用计划工具。

## 轻量风险提示

当下建议里可以出现轻量风险提示：

- 记录不足：提醒今天补齐关键记录。
- 今日或近几天奶量波动：提醒今天先稳住排乳间隔。
- 连续低于或高于参考：提示需要进一步聊清楚目标和约束。
- 宝宝摄入或生长信号不清楚：提醒观察尿布、精神、体重记录，并邀请继续分析。

如果风险需要进入完整流程，下一步是读取 `analysis.md` 或 `advice-plan.md`，不要在当下建议里直接生成计划。
