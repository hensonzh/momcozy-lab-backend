# 当下建议

这个 reference 用来回答“今天/现在/下一步怎么做”。它只给当下动作，不做完整追奶、稳奶或减奶计划。

## 什么时候用

- 用户问今天怎么吸、现在先做什么、今天奶量要注意什么。
- 用户只想要一个今天能执行的小建议。
- 分析结果提示先补记录、先稳住节奏或先观察当天变化。

## 怎么做

需要工具时，先用 `tool_search` 加载 `milk_management` namespace。

1. 需要看今天安排时，用 `milk_calendar_query`。
2. 需要看今日状态或趋势概览时，用 `milk_status_query`。
3. 需要看过去记录时，用 `milk_records_query`。
4. 只有用户问是否正常、够不够、偏低/偏高、是否需要计划时，才转 `analysis.md`。

如果回答里提到“原计划、今天安排、未来几天先这样做”，必须以 calendar 或已保存计划为准。真实吸奶记录只能说明实际发生过什么，不能当成原计划。

## 回复方式

按这个顺序短一点说：

1. 今天最重要的状态。
2. 今天优先处理的一件事。
3. 现在可以做的动作。
4. 是否需要继续分析或制定计划。

示例：

```markdown
今天先别急着猛加任务。

你可以先把排乳间隔稳住，再确认有没有漏记亲喂或手挤记录。

如果这些记录已经完整，我可以接着帮你看是否需要做追奶计划。
```

## 不要做

- 不生成完整计划。
- 不写入日程。
- 不手工编排未来 3 天或 7 天吸奶时间。
- 不把一次当下建议直接升级成计划，除非用户确认想做计划。
