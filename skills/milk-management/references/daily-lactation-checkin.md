# 每日泌乳建议

本 reference 用于生成或承接“每日泌乳建议”。它是 daily check-in，不是完整追奶、稳奶或减奶计划。

## 定位

每日泌乳建议只回答“今天怎么做更合适”。可以参考过去 24 小时、最近几天趋势、今日任务和记录完整性，但输出必须落在今天的行动上。

每日泌乳建议可以提示风险，但不直接生成长期计划；如果需要完整计划，转入 `milk-risk-intervention.md` 或 `milk-plan-creation.md`。

## 适用场景

- 用户要“每日泌乳建议”“今天怎么吸”“今天奶量要注意什么”。
- 前端已经生成每日泌乳建议卡片，用户继续追问其中的状态、原因或下一步。
- 用户只想要今天的执行建议，而不是完整追奶、稳奶或减奶计划。

不适用：

- 用户明确要做追奶、稳奶或减奶计划：读取 `milk-plan-creation.md`。
- 用户表达奶量风险、宝宝摄入担心或是否转奶粉：读取 `milk-risk-intervention.md`。
- 出现红旗症状：停止每日建议流程，回到 `SKILL.md` 的红旗边界处理。

## 数据使用

需要工具时，先通过 `tool_search` 加载 `milk_management` namespace。

- 看今天安排、未完成任务或日程执行：用 `milk_calendar_query`。
- 看今日状态页信息、趋势或宝宝成长概览：用 `milk_status_query`。
- 只看过去一段时间记录和每日汇总：用 `milk_records_query`。
- 只有用户明确问“是否正常、够不够、偏低偏高、是否需要计划”时，才调用 `milk_assessment_evaluate`。

不要为了每日建议默认生成计划草稿，也不要调用写入工具。

## 输出结构

建议按下面四块组织，但可以压缩成自然短段：

1. **今日状态**：稳定、记录补充中、奶量波动中、需要关注等短状态。
2. **今日重点**：今天最值得优先处理的一件事。
3. **今天怎么做**：只给今天可执行动作，例如按日程吸奶、避免间隔过长、补齐记录、观察身体感受。
4. **是否需要继续聊**：如果存在风险或用户有担心，邀请进入奶量问题对话；不要直接给长期计划。

## 边界

- 不单独输出“喂养建议”段落；喂养数据只作为理解泌乳和宝宝摄入的背景。
- 不把连续异常直接写成“你需要追奶/减奶”。只能说“可能需要进一步看一下是否要调整计划”。
- 不承诺今天执行后奶量一定变化。
- 不写入 calendar；如果用户要调整日程，转 `calendar-adjustment.md`。
- 不生成完整追奶、稳奶或减奶计划；如果用户确认想做计划，转 `milk-risk-intervention.md` 或 `milk-plan-creation.md`。

## 风险提示的处理

每日建议里可以出现轻量风险提示：

- 记录不足：提醒今天补齐关键记录。
- 今日或近几天奶量波动：提醒今天先稳住排乳间隔。
- 连续低于或高于参考：提示需要进一步聊清楚目标和约束。
- 宝宝摄入或生长信号不清楚：提醒观察尿布、精神、体重记录，并邀请继续评估。

如果风险需要进入完整流程，下一步是读取 `milk-risk-intervention.md`，不要在每日建议里直接进入计划生成。
