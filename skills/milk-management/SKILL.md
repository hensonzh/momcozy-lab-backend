# 奶量管理

本 skill 是奶量管理的入口索引。先判断用户属于哪类任务，再读取对应 reference 或加载 `milk_management` namespace。工具字段、参数和副作用边界以工具 schema 为准。

## 职责边界

- 覆盖：奶量、吸奶、亲喂、母乳瓶喂、奶粉瓶喂、宝宝生长、泌乳计划、计划执行、calendar 日程。
- 不覆盖：设备故障、待产包、情绪支持的独立流程；这些场景切到对应 skill。
- 普通概念解释、轻量担心或单条记录解释，可以直接回答；不要自动升级成综合评估或计划。
- 读取、评估、预览、写入都通过 `milk_management` deferred namespace 中的工具完成；需要工具时先用 `tool_search` 加载该 namespace。

## 路由优先级

按下面顺序判断。命中高优先级场景时，不要继续走低优先级流程。

1. **红旗症状**
   - 触发：用户描述严重、持续加重、伴随全身症状，或宝宝状态无法保证安全的情况。
   - 行动：停止普通奶量管理流程，按下方“红旗边界”处理。

2. **综合概览与分流**
   - 触发：用户明确要综合分析最近奶量、吸奶、母乳、宝宝状态、风险或整体数据，且没有指定记录修改、今日安排、计划保存等具体子任务。
   - 行动：读取 `references/overview-triage.md`。只做只读概览和下一步分流，不直接生成或保存计划。

3. **每日泌乳建议**
   - 触发：用户要“每日泌乳建议”“今天怎么安排吸奶”“今天奶量重点”“今天要注意什么”，或前端已经生成每日泌乳建议卡片后继续追问。
   - 行动：读取 `references/daily-lactation-checkin.md`。

4. **奶量风险提示与计划前置对话**
   - 触发：用户表达“奶量不够”“宝宝是不是吃不饱”“最近奶少了”“要不要转奶粉”“要不要追奶/减奶/稳奶”，或每日建议/综合概览已提示风险而用户愿意继续聊。
   - 行动：读取 `references/milk-risk-intervention.md`。

5. **追奶、稳奶、减奶计划**
   - 触发：用户明确要求生成、修改、保存追奶/稳奶/减奶计划。
   - 行动：读取 `references/milk-plan-creation.md`。

6. **今日安排、日结与任务完成**
   - 触发：用户问今天安排、今日日结、完成率、顺延、标记完成、取消完成、跳过任务。
   - 行动：读取 `references/calendar-adjustment.md`。

7. **calendar 日程调整**
   - 触发：用户新增、修改、删除会占用时间的事项，调整吸奶/亲喂日程，或发送图片让你识别行程后重排日程。
   - 行动：读取 `references/calendar-adjustment.md`。

8. **情绪化但非红旗的奶量场景**
   - 触发：用户明显焦虑、自责、挫败或害怕宝宝吃不饱，但还没有要求数据评估或计划。
   - 行动：按全局 CoMate 回复风格先承接，再只问能推动下一步的 1 个关键信息；如果用户随后要看数据、风险或计划，再按上面的对应路径走。

9. **普通数据查询或评估**
   - 触发：用户只问某个时间段记录、状态页数据、趋势、宝宝成长记录、已有计划或某项是否正常。
   - 行动：加载 `milk_management` namespace 后，按工具 schema 选择查询或评估工具。只读查询不等于计划生成。

## 工具原则

- `*_get` / `*_query` 读取事实；`*_evaluate` 做规则评估；`*_preview` 返回候选方案；`*_mutate` 和任务完成类工具有副作用。
- 写入、修改、删除、顺延、确认完成、保存计划前，必须先明确即将影响的对象、日期、时间范围和结果，并获得用户确认。
- 用户的“好/可以/继续”只有在上一轮已经给出单一、明确的下一步时，才表示继续该流程；如果涉及写入但对象或影响不明确，必须先复述并再次确认。
- 不把一次记录查询自动扩展成综合评估，也不把一次评估自动扩展成计划。
- 亲喂奶量如来自工具估算，最终解释中必须说明是估算，不当作实测值。

## 安全边界

- 不诊断疾病，不开药，不保证奶量结果。
- 宝宝红旗优先儿科或急诊；乳房/全身红旗优先医生、产科、乳腺门诊或产后门诊。

## 红旗边界

当用户描述严重、持续加重、伴随全身症状，或宝宝状态无法保证安全时，暂停普通奶量管理流程。

- 乳房/哺乳相关：严重或加重的乳房疼痛、红肿硬块、发热寒战、异常分泌物、胸痛、呼吸困难、意识异常等。
- 宝宝相关：明显精神反应差、不易唤醒、持续拒奶或进食差、尿布显著减少或疑似脱水、持续呕吐、体温异常、发蓝发灰、呼吸困难、抽搐等。

应对方式：

- 先用一句话承接用户当下的紧张、疼痛或担心。
- 简短说明这类情况需要专业人员判断，不继续做奶量计划或居家处理指导。
- 乳房/全身问题优先建议联系医生、产科、乳腺门诊或产后门诊。
- 宝宝问题优先建议联系儿科、儿童急诊或当地急救。
- IBCLC 只能作为等待就医或喂养衔接支持，不能替代医生或儿科。
